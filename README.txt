Εργαστήριο ΨΕΣ how to work 


15/10/26 αναρτήθηκε η εκφώνηση της 1ης άσκησης για το εργαστήριο ΨΕΣ 
29/10/26 προθεσμία υποβολής 1ης άσκησης

Η πρώτη άσκηση ζητάει την επίλυση 3ον ασκήσεων ο κώδικας κάθε άσκησης θα αναρτηθεί ξεχωριστά και η αναλυτική αναφορά 

Περιεχόμενο της αναφοράς όπως προβλέπει ο καθηγητής:

-    Φροντίστε να συμπεριλάβετε στην αναφορά τις θεωρητικές γνώσεις που απαιτούνται για να υλοποιήσετε τις ασκήσεις και να επιβεβαιώσετε τα αποτελέσματα που πήρατε.

-    Συμπεριλάβετε στην αναφορά σας τις γραφικές παραστάσεις - σχήματα που προέκυψαν σε κάθε  ερώτημα, χωρίς τους αντίστοιχους κώδικες Python. Αυτοί παραδίδονται σε ξεχωριστό ηλεκτρονικό αρχείο, μαζί με σύντομες οδηγίες εκτέλεσης.

-    Τα γραφήματα να περιλαμβάνουν, απαραιτήτως: κεντρικό τίτλο και τίτλους στους άξονες και να εμφανίζεται όλο το «χρήσιμο» εύρος των σημάτων σας για την εξαγωγή των συμπερασμάτων.

-    Περιγράψτε σύντομα την υλοποίηση σε κάθε ερώτημα, καταγράφοντας συμπεράσματα ή παρατηρήσεις όπου προκύπτουν. Στόχος είναι να φανεί η κριτική σας ικανότητα και σκέψη και όχι απλά να παρατίθεται ο κώδικας και τα αποτελέσματα από το προγραμματιστικό περιβάλλον. Σημαντικό είναι (και θα αξιολογηθείτε σε αυτό) να μπορέσετε  να κάνετε μία σύντομη περιγραφή του τι κάνατε σε κάθε ερώτημα, πώς υπολογίσατε ό,τι χρειάστηκε να υπολογίσετε και πού βασίστηκε η σκέψη σας για να υλοποιήσετε την άσκηση (π.χ. μην αναφέρεστε απευθείας σε αποτελέσματα, αλλά δείξτε ποιον τύπο ή σχέση της θεωρίας χρειαστήκατε).


Σημαντική είναι επίσης η ανάπτυξη σχολίων στο κώδικα τα οποία να εξηγούν τις βασικές παραμέτρους/μεταβλητές.
