## Εκτέλεση

Ανοίξτε τον φάκελο του αποθετηρίου στο VS Code ή σε τερματικό. Δοκιμάστηκε με Python 3.12, NumPy 2.5.4 και Matplotlib 3.11.2.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r lab1/requirements.txt
python lab1/exercise1.py --fs 1
python lab1/exercise2.py
python lab1/exercise3.py
python lab1/verify.py
```

Στα Windows χρησιμοποιήστε `python -m venv .venv` και ενεργοποιήστε το περιβάλλον με `.venv\Scripts\activate.bat` στο Command Prompt ή `.venv\Scripts\Activate.ps1` στο PowerShell. Οι επόμενες εντολές είναι ίδιες. Στο VS Code επιλέξτε τον διερμηνέα Python μέσα στη `.venv`.

Οι τρεις ασκήσεις παράγουν εννέα PNG στον φάκελο `lab1/figures/`. Δεν απαιτούνται MATLAB ή SciPy. Σε περιβάλλον χωρίς οθόνη χρησιμοποιήστε `MPLBACKEND=Agg`. Το `verify.py` εκτελεί 18 ανεξάρτητους ελέγχους των αποτελεσμάτων και της αναπαραγωγής αρχείων.

## Παράμετροι

- **1Β:** η εκφώνηση δεν δίνει συχνότητα δειγματοληψίας. Χρησιμοποιείται η σύμβαση `fs = 1 Hz` (`Ts = 1 s`) για τον άξονα σε Hz. Η αβεβαιότητα αναφέρεται ρητά στην αναφορά. Η εκτέλεση χωρίς `--fs` χρησιμοποιεί επίσης 1 Hz· κάθε εκτέλεση ανανεώνει το αντίστοιχο διάγραμμα.
- **2:** βήμα 1 ms για τη σχεδίαση της συνεχούς καμπύλης· οι περίοδοι δειγματοληψίας είναι ακριβώς αυτές της εκφώνησης. Τα άκρα των χρονικών διαστημάτων εξαιρούνται.
- **3Α:** 128 δείγματα στα 256 Hz· το `+30` ερμηνεύεται σε rad. Για το συγκεκριμένο μήκος και τις συγκεκριμένες συχνότητες, η εναλλακτική ερμηνεία σε μοίρες δίνει το ίδιο φάσμα μέτρου εντός `1e-12`.
- **3Β:** φάση 0 rad, 400 δείγματα και fs = 20 kHz.

Οι ελληνικές εικόνες στο `figures/el/` έχουν τα ίδια δεδομένα με τις εξόδους των ασκήσεων, με ελληνικές επιγραφές. Με αλλαγή της λύσης πρέπει να ενημερώνονται οι εικόνες και οι αντίστοιχες εκδόσεις PDF/HTML μαζί με τα κείμενα.
